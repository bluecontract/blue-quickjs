# @blue-quickjs/deterministic-builder

Facade package for deterministic builder APIs.

This package re-exports the builder functionality currently implemented in
`@blue-quickjs/deterministic-bundler`:

- `buildDeterministicModulePack(...)`
- `bundleDeterministicProgram(...)`
- `scanCompatibility(...)`

Build/test:

- `pnpm nx build deterministic-builder`
- `pnpm nx test deterministic-builder`
